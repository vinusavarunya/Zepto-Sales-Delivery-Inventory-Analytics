### **Zepto Sales, Delivery \& Inventory Analytics Dashboard Project Overview**



*This project is an end-to-end Business Intelligence solution built using SQL and Power BI.*



*The dashboard analyzes sales performance, delivery efficiency, customer behavior, profitability, inventory levels, and product performance for a Zepto-style quick-commerce business*.

# \------------------------------------------------------------------

### **Tools Used**



* *SQL*
* *Power BI*
* *Power Query*
* *DAX*
* *Data Modeling*



\-----------------------------------------------------------------------------------------------------------------------------------------------------------------------



### **Business Objectives**



* Analyze revenue and profit trends
* Monitor delivery SLA performance
* Evaluate city-wise order performance
* Identify top-performing products and brands
* Track inventory availability
* Measure customer satisfaction and cancellation rates

\------------------------------------------------------------------------------------------------------------------------------------------------------------------------



### **Data Cleaning : Performed using Power Query**



* Removed duplicates
* Validated data types
* Handled null values
* Trimmed and cleaned text fields
* Created Delivery SLA column
* Created Date hierarchy columns
* Created Profit Per Unit column

### **Key Insights**



1. Atta, Rice, Oil \& Dals generated the highest revenue.
2. Chennai recorded the highest number of orders.
3. UPI contributed the largest share of revenue.
4. Most orders were delivered within SLA targets.
5. A small number of brands contributed a significant portion of revenue.
6. Inventory levels varied across categories highlighting stock optimization opportunities.
